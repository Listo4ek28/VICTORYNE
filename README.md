# 🎯 VICTORYNE+ — Платформа для викторин



Веб-приложение для создания, прохождения и управления викторинами с системой регистрации, статистикой и админ-панелью.



---



## 🚀 Возможности



### Для всех пользователей

- \*\*Регистрация и авторизация\*\* — создание аккаунта с аватаром

- \*\*Выбор темы викторины\*\* — удобный поиск по темам

- \*\*Викторина с таймером\*\* — вопросы разной сложности (лёгкие, средние, сложные)

- \*\*Подсчёт очков\*\* — баллы зависят от сложности вопроса

- \*\*История и статистика\*\* — просмотр результатов и прогресса

- \*\*Рейтинг игроков\*\* — топ-10 лучших участников

- \*\*Личный кабинет\*\* — изменение аватара и имени пользователя



### Для администраторов

- \*\*Управление темами\*\* — создание и удаление тем викторин

- \*\*Управление вопросами\*\* — добавление/удаление вопросов с вариантами ответов

- \*\*Управление сложностью\*\* — настройка уровня сложности каждого вопроса

## Старт:

* клонировать репозиторий
* создать базу данных на вашем сервере
* поместить файлы в корневую директорию: your\_domain.com/\[файлы]
* подставить в api.php свою базу данных:

  * $host = "localhost";
  * $dbname = "VICTORYNE";
  * $username = "ваш\_пользователь";
  * $password = "ваш\_пароль";
* импортируйте init.sql в вашу бд
* Откройте в браузере: http://your\_domain.com
